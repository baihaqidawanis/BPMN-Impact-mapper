# Riwayat eksperimen

Folder simple-erp menyimpan paket lama untuk regresi dan provenance. Gunakan ../simple-erp/current-staff-v2 untuk percobaan baru.

JSON snapshot/freeze mempertahankan isi dan hash aslinya. Path yang tersimpan merekam lokasi saat penelitian dilakukan; beberapa instruksi historis tidak langsung berlaku pada susunan folder baru. Research freeze reader mendukung relokasi paket lama tanpa menulis ulang kunci jawaban atau hash.
