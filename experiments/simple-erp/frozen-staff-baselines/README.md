# Baseline historis untuk eksperimen lama

Dua file ini identik byte-for-byte dengan baseline sebelum normalisasi Staff
29 Oktober 2026. Hash dicocokkan dengan kedua manifest Staff sebelum path input
dipindahkan ke sini. Label acuan, hash input dan tabel hasil tidak diubah.

Gunakan baseline ini untuk mutasi/benchmark lama. Untuk skenario baru, salin dan
edit baseline Staff kanonis yang sudah dinormalisasi di Simple-ERP. Jangan
membandingkan baseline baru satu end dengan mutasi lama beberapa end kecuali
memang sedang menguji perubahan notasinya.

Repository input tetap source Simple-ERP. File-file ini bukan retrieval corpus.
Fingerprint repository tetap harus cocok; salinan BPMN saja tidak membekukan
seluruh working tree ERP atau menjamin reproduksi jika source berubah.
